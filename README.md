# Zwanzig Panels auf zwanzig Kilobyte

Ein Erfahrungsbericht über adaptive Abtastung, Quellenfusion und Speicherdisziplin
auf einem ESP32 mit rund 20 kB freiem Heap.

**Zu lesen unter https://achiim.github.io/zwanzig-kilobyte/**

Dieses Repository enthält nur den Artikel. Es dient dazu, ihn über GitHub Pages
veröffentlichen zu können — das Projekt selbst liegt anderswo.

| Datei | |
|---|---|
| `index.html` | der Artikel, eine einzige Datei ohne Abhängigkeiten außer den Schriften |
| `vorschau.png` | Vorschaubild für geteilte Verlinkungen |
| `.nojekyll` | hält die Dateien von GitHubs Jekyll-Verarbeitung fern |
